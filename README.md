# 방치형 RPG (Idle Battle)

브라우저에서 바로 실행되는 단일 HTML 방치형 게임입니다.

- 실행: `index.html` 을 브라우저로 열기
- 배포: GitHub Pages → https://kuzuni.github.io/zz1/

## 규칙
- 왼쪽 플레이어와 오른쪽 적이 자동으로 1:1 전투
- 적을 때릴 때마다 골드, 처치 시 타격 골드의 10배
- 보스 도전: 일반 적의 10배 능력치, 클리어 시 다음 스테이지
- 보스 최초 클리어는 일반 처치의 10배 골드, 재클리어는 일반 처치와 동일
- 스테이지가 오를수록 적 능력치와 골드 획득량 증가
- 능력치: 공격력 / 공격속도 / 체력 / 체력회복
- 디버그 창: 공격력·공격속도·체력회복·체력·골드 획득량 배율을 숫자로 직접 입력
